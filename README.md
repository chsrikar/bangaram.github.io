# Happy Birthday, Ammulu! ❤️

A romantic, interactive birthday celebration website created with love for Ammulu.

## ✨ Features
- **Intro & Music**: Romantic birthday greetings and background melody.
- **Interactive Balloons**: Pop celebratory balloons with sweet hidden messages.
- **Birthday Cake**: Make a wish and blow out candles.
- **Flower Bouquet**: Collect beautiful roses and flowers.
- **Love Envelope & Letter**: Wax-sealed letter with typewriter effect, personalized romantic couple keepsake photo, and heartfelt love letter.
- **Gift Box**: Unbox a sweet birthday surprise.
- **Secret Scratch Card**: Touch/mouse scratchable rose-gold foil revealing a hidden love note.
- **Birthday Love Coupons**: Interactive redeemable coupons with stamp effect.
- **Reasons Why I Love You**: Sweet cards with heartfelt reasons.
- **Grand Finale**: Festive fireworks and celebration.

## 🚀 Running Locally
Simply double-click `start.bat` or open `index.html` in any modern web browser.
